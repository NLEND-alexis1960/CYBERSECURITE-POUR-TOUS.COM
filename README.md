# CYBERSECURITE-POUR-TOUS.COM

Qu'est-ce que Cybersécurité pour Tous ? Cybersécurité pour Tous est une plateforme SaaS complète de protection des données et de fidélisation client. Elle permet aux TPE et PME françaises de :  🔒 Surveiller automatiquement leurs sauvegardes quotidiennes

## Getting Started

This is a [Next.js](https://nextjs.org) project with Vercel Web Analytics integrated.

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Vercel Web Analytics

This project has been configured with [Vercel Web Analytics](https://vercel.com/docs/analytics) to track visitor data and page performance.

The Analytics component is integrated in `app/layout.tsx` and will automatically track page views when deployed to Vercel.
